# MusicBrainz Cover

`@id atom.musicbrainz-cover` · `@type source` · `@apiLevel 1`

仅注册 `musicbrainz` 源的 `musicSearch` 与 `musicPic`。宿主在曲目完全没有封面时调用插件；已有封面的曲目继续使用原封面。插件不提供播放地址、歌词或评论，不写入曲目标签。

## 查询流程

1. 收到宿主拼接的“曲名 艺术家”关键词。将每个文字/数字 token 转为录音名或艺术家的带引号条件，转义搜索语法，避免猜测曲名与艺术家的分界。
2. MusicBrainz recording search 默认取 100 条录音，以免热门歌曲的多个混音/再版挤掉原始录音。只返回具有有效时长和发行信息的录音；每条录音最多保留六个专辑候选，总数最多 400。
3. 候选带 `name`、`singer`、`album`、`durationMs` 供宿主匹配；`releaseId`、同专辑的 `releaseIds`、`releaseGroupId` 是插件自己的透传字段。发行版优先官方专辑、降低精选集/现场版顺序，同一组与相同专辑名合并。
4. 宿主选择候选后，先查该发行版的 CAA JSON；未得到正面封面时查该 release group 的精选封面，再在预算允许时尝试最多两份同专辑发行版。
5. 只返回标为 `front: true` 的图片，优先 1200px，其次 500/250px 和原图；校验 CAA/Archive 图片地址并使用 HTTPS。没有正面封面返回空 URL。

## 请求与缓存

- 所有网络请求走 `splayer.request`；包含插件名、版本、维护者联系地址的 User-Agent。
- MusicBrainz 实际请求起点间隔至少 1100ms，同关键词合并请求，等待队列有上限；HTTP 429/503 后退避，不自动连续重试。
- 搜索网络超时 7 秒，排队最多约 5 秒；封面每次网络请求最多 6.5 秒，整个封面处理预算 13.5 秒，低于宿主动作的 15 秒期限。
- 搜索缓存为内存缓存，10 分钟、最多 48 项。封面缓存通过 `splayer.storage` 持久化，成功保留 7 天、404/无正面封面保留 1 小时、最多 128 项；网络错误不写入负缓存。
- 服务不可达、数据异常或无匹配时返回空结果，由宿主继续原有行为。

## 能力边界

`musicSearch` 不接收原始 Track 或专辑名。专辑只能作为候选返回，由宿主自己的专辑加分选择；插件无法精确指定实体版本，也不能保证所有同名发行版都被包含。

缺少 MusicBrainz 时长的录音被跳过，保证宿主时长门槛有效。双方时长相差超过 20 秒时，宿主排除候选。关键词过长、复杂古典命名、艺术家别名、多语言及数据库未收录曲目仍可能无匹配。

CAA 记录中的图片存在不等于每一个缩略图下载都可达；最终图片由宿主/浏览器加载。图片用途和权利由原权利人决定。

MusicBrainz 的每 IP 约一请求/秒限制跨应用共享；插件只控制自己的请求，其他客户端仍可能导致服务限流。详见 [官方说明](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting)。
